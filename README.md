## О проекте
Мы разрабатываем **интерактивный брендбук компании «PLANET.EXE»** — цифровое пространство, в котором будут представлены основные элементы фирменного стиля и правила их использования.

PLANET.EXE — концептуальный бренд экологичных технологий и интерактивный цифровой брендбук. Проект объединяет природные образы, технологический дизайн и эстетику Frutiger Aero: прозрачные поверхности, воду, зелень, глянцевые иконки и интерфейс в духе Windows XP. 

Брендбук представлен в виде рабочего стола Planet OS 2004. Вместо обычного каталога пользователь изучает фирменный стиль через приложения, окна и интерактивные инструменты.
